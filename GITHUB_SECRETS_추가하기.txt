========================================================================
  GitHub Secrets 추가 방법 (3분이면 완료!)
========================================================================

브라우저에서 GitHub Secrets 페이지가 열렸습니다!

------------------------------------------------------------------------
추가할 Secret 1:
------------------------------------------------------------------------
버튼 클릭: "New repository secret"

입력:
  Name:   EKS_CLUSTER_NAME
  Secret: chat-prod

"Add secret" 버튼 클릭

------------------------------------------------------------------------
추가할 Secret 2:
------------------------------------------------------------------------
버튼 클릭: "New repository secret"

입력:
  Name:   K8S_CLUSTER_TYPE  
  Secret: EKS

"Add secret" 버튼 클릭

========================================================================
완료 후 실행할 명령어:
========================================================================

1. 모든 파일 커밋:
   git add .

2. 커밋 메시지 작성:
   git commit -m "chore: Kubernetes CI/CD 설정 완료"

3. GitHub에 푸시:
   git push origin main

4. GitHub Actions 확인:
   https://github.com/choimeyoung94/final_project_coreconnect/actions
