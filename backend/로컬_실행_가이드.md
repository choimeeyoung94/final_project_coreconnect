# 🚀 로컬 개발 환경 실행 가이드

## ✅ 새로 추가된 파일들

1. **`application-local.properties`** - 로컬 개발용 설정
2. **`application-local.yml`** - Redis 비활성화 설정
3. **이 파일** - 실행 가이드

## 📋 방법 1: IntelliJ IDEA에서 실행 (추천)

### 1단계: Active Profile 설정

1. **Run** → **Edit Configurations** 클릭
2. **Spring Boot** → **BackendApplication** 선택
3. **Active profiles** 항목에 `local` 입력
4. **Apply** → **OK** 클릭

### 2단계: 실행

- **Run** 버튼 클릭 또는 `Shift + F10`

## 📋 방법 2: application.properties 수정

### `application.properties` 파일 수정

64번 줄을 다음과 같이 변경:

```properties
# 변경 전
spring.profiles.active=secure

# 변경 후
spring.profiles.active=local
```

## 📋 방법 3: 명령줄에서 실행

### Windows (cmd)
```bash
cd backend
gradlew bootRun --args="--spring.profiles.active=local"
```

### Windows (PowerShell)
```powershell
cd backend
.\gradlew bootRun --args="--spring.profiles.active=local"
```

### Mac/Linux
```bash
cd backend
./gradlew bootRun --args="--spring.profiles.active=local"
```

## 🎯 로컬 프로필의 특징

### ✅ 장점

1. **MySQL 불필요** - H2 인메모리 데이터베이스 사용
2. **Redis 불필요** - Redis 없이도 실행 가능
3. **보안 OFF** - JWT 인증 없이 모든 API 접근 가능
4. **자동 테이블 생성** - 매번 실행 시 테이블 자동 생성
5. **외부 서비스 불필요** - AWS S3, SendGrid 없이도 실행

### ⚠️ 주의사항

1. **데이터 휘발성** - 서버 재시작 시 모든 데이터 삭제
2. **파일 업로드** - S3 설정이 없어서 파일 업로드 기능은 에러 발생 가능
3. **이메일 발송** - SendGrid 설정이 없어서 이메일 발송 기능은 에러 발생 가능

## 🗄️ H2 Database 콘솔 접속

애플리케이션 실행 후:

1. 브라우저에서 http://localhost:8080/h2-console 접속
2. 다음 정보 입력:
   - **JDBC URL**: `jdbc:h2:mem:coreconnect`
   - **User Name**: `sa`
   - **Password**: (빈 칸)
3. **Connect** 클릭

→ SQL 쿼리 직접 실행 및 테이블 확인 가능!

## 🔧 문제 해결

### 1. H2 의존성 없음 에러

`build.gradle`에 H2 의존성 추가:

```gradle
dependencies {
    // H2 Database (로컬 개발용)
    runtimeOnly 'com.h2database:h2'
}
```

### 2. Redis 연결 에러

이미 설정에서 비활성화했지만, 에러가 계속 나면:

**`application-local.yml`** 확인:
```yaml
spring:
  autoconfigure:
    exclude:
      - org.springframework.boot.autoconfigure.data.redis.RedisAutoConfiguration
```

### 3. Port 8080 이미 사용 중

**`application-local.properties`**에 추가:
```properties
server.port=8081
```

## 💡 추가 팁

### 프로덕션 환경으로 다시 돌아가기

**방법 1**: Active profile을 `secure`로 변경

**방법 2**: `application.properties` 64번 줄 원복
```properties
spring.profiles.active=secure
```

### 로컬에서 실제 MySQL 사용하고 싶다면

**`application-local.properties`** 수정:

```properties
# H2 대신 MySQL 사용
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.datasource.url=jdbc:mysql://localhost:3306/coreconnect?useSSL=false&serverTimezone=Asia/Seoul&allowPublicKeyRetrieval=true
spring.datasource.username=root
spring.datasource.password=your_actual_password

spring.jpa.database-platform=org.hibernate.dialect.MySQLDialect
```

단, MySQL 서버가 실행 중이어야 하고 `coreconnect` 데이터베이스가 생성되어 있어야 합니다.
