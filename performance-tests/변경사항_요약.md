### 1. config.js (289줄)

**경로**: `performance-tests/config.js`

**역할**: 모든 테스트 스크립트의 공통 설정

**주요 내용**:

#### 환경 설정
```javascript
export const BASE_URL = __ENV.BASE_URL || 'http://localhost:8080';
export const WS_URL = __ENV.WS_URL || 'ws://localhost:8080';
```
- 테스트 대상 서버 URL 정의
- 환경 변수로 오버라이드 가능

#### 테스트 시나리오 (4가지)
1. **smoke**: 스모크 테스트 (5 VU, 1분)
2. **load**: 부하 테스트 (0→50→100 VU, 16분)
3. **stress**: 스트레스 테스트 (0→100→200→300 VU, 24분)
4. **spike**: 스파이크 테스트 (급격하게 500 VU, 8분)

#### 성능 임계값 (Thresholds)
```javascript
export const THRESHOLDS = {
  http_req_failed: ['rate<0.01'],        // 실패율 < 1%
  http_req_duration: ['p(95)<500'],      // P95 < 500ms
  http_req_duration: ['p(99)<1000'],     // P99 < 1000ms
  ws_connecting: ['p(95)<1000'],         // WebSocket 연결 < 1s
};
```

#### 테스트 사용자
```javascript
export const TEST_USERS = [
  { email: 'test1@coreconnect.com', password: 'password123' },
  { email: 'test2@coreconnect.com', password: 'password123' },
  // ... 총 5명
];
```

#### JWT 토큰 획득 함수
```javascript
export function getAuthToken(email, password) { ... }
```

**수정 필요 사항**:
- `TEST_USERS` 배열을 실제 환경의 테스트 계정으로 변경
- `getAuthToken()` 함수의 토큰 추출 로직을 API 응답 구조에 맞게 수정

### 2. chat-test.js (338줄)

**경로**: `performance-tests/chat-test.js`

**역할**: 채팅 기능 부하 테스트

**테스트 흐름**:
```
1. 로그인 → JWT 토큰 획득
   ↓
2. 채팅방 생성 (10% 확률)
   ↓
3. REST API로 메시지 전송 (50% 확률)
   ↓
4. 메시지 목록 조회
   ↓
5. 미읽은 메시지 개수 조회
   ↓
6. WebSocket STOMP 실시간 채팅 (30% 확률)
```

**테스트하는 API**:
- `POST /api/v1/chat` - 채팅방 생성
- `POST /api/v1/chat/rooms/{roomId}/messages` - 메시지 전송
- `GET /api/v1/chat/{roomId}/messages` - 메시지 조회
- `GET /api/v1/chat/rooms/{roomId}/messages/unread-count` - 미읽은 개수
- WebSocket: `/ws/chat` (STOMP)

**커스텀 메트릭**:
- `chat_messages_sent`: 전송된 메시지 수
- `chat_messages_received`: 수신된 메시지 수
- `chat_rooms_created`: 생성된 채팅방 수
- `chat_message_latency`: 메시지 지연시간
- `ws_connection_time`: WebSocket 연결 시간

**WebSocket STOMP 흐름**:
1. `/ws/chat` 연결
2. CONNECT 프레임 전송
3. `/topic/chat/{roomId}` 구독
4. `/app/chat.sendMessage`로 메시지 전송
5. 30초간 연결 유지 후 종료

**수정 필요 사항**:
- 라인 85-87: API 응답에서 `roomId` 추출 로직
- 라인 190: 기본 채팅방 ID를 실제 존재하는 ID로 변경
