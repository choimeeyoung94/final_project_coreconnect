
### 🚨 병목 지점 분석

#### 1. 채팅 메시지 브로드캐스팅
```java
// AS-IS: 동기 처리
@MessageMapping("/chat.send")
public void sendMessage(ChatMessage message) {
    // 1. DB 저장 (50ms)
    chatRepository.save(message);
    
    // 2. 같은 채팅방의 모든 사용자에게 전송 (N * 10ms)
    List<User> roomUsers = userRepository.findByRoomId(roomId);  // 100ms
    for(User user : roomUsers) {  // 1,000명이면 10초
        messagingTemplate.convertAndSendToUser(
            user.getId(), 
            "/queue/messages", 
            message
        );  // 10ms/user
    }
}
```

**문제점:**
- 1,000명 채팅방에서 메시지 1개 전송 시: **10.15초 소요**
- DB 커넥션 고갈 (HikariCP 40개 → 1초에 4개만 처리 가능)
- 메모리 고갈 (1,000개 WebSocket 세션 동시 처리)
- 순차 처리로 인한 앞 사용자 우선, 뒷 사용자 지연

#### 2. 실시간 알림
```java
// AS-IS: DB 폴링
@Scheduled(fixedDelay = 3000)  // 3초마다
public void checkNewNotifications() {
    List<User> activeUsers = sessionManager.getActiveUsers();  // 1,000명
```

**문제점:**
- 1,000명 * 3초 = 초당 333개 쿼리 (DB 부하)
- 실시간성 부족 (최대 3초 지연)
- 스케일 아웃 불가 (각 서버가 중복 쿼리)

#### 3. 읽지 않은 메시지 카운트

## 2. 채팅 시스템 개선 (1,000~100,000명 동시 접속)

### 🎯 개선 목표

| 지표 | AS-IS (20명) | 목표 (1,000명) | 목표 (100,000명) |
|------|--------------|----------------|-------------------|
| 메시지 전송 응답 | 250ms | 50ms | 100ms |
| 브로드캐스트 시간 | 10.15s | 200ms | 500ms |
| 메시지 처리량 | 15 msg/s | 5,000 msg/s | 50,000 msg/s |
| 동시 연결 | 20 connections | 1,000 connections | 100,000 connections |

### 📐 아키텍처 개선안

#### AS-IS 아키텍처
```
[Client] → [WebSocket] → [Spring Boot] → [MySQL]
                              ↓
                         [1:N 순차 전송]
                              ↓
                       [1,000명에게 전송]
                         (10초 소요)
```

#### TO-BE 아키텍처
```
[Client] → [WebSocket] → [Spring Boot] → [Redis Pub/Sub] → [구독 서버들]
                              ↓                                  ↓
                          [Kafka]                          [WebSocket Push]
                              ↓                            (100ms, 병렬)
                          [MySQL]
                        (비동기 저장)
```

### 🔧 개선안 1: Redis Pub/Sub를 활용한 실시간 브로드캐스팅

#### 기술 선택 이유

| 기술 | 선택 이유 | 성능 |
|------|-----------|------|
| **Redis Pub/Sub** | - 인메모리 기반 초고속 메시지 전달<br>- 1,000,000+ 메시지/초 처리<br>- 여러 Spring Boot 서버 간 메시지 동기화<br>- WebSocket Cluster 지원 | **100,000 msg/s** |
| WebSocket만 사용 시 | 단일 서버만 처리 → 스케일 아웃 불가 | 15 msg/s |
| Kafka만 사용 시 | 영속성 보장하지만 실시간성 부족 (100ms 지연) | 1,000 msg/s |

#### 구현 코드

```java
// ======================================
// 1. Redis Pub/Sub 설정
// ======================================
@Configuration
@EnableRedisWebSocketMessageBroker
public class RedisWebSocketConfig {
    
    @Bean
    public RedisMessageListenerContainer redisMessageListenerContainer(
            RedisConnectionFactory connectionFactory,
            MessageListenerAdapter listenerAdapter) {
        
        RedisMessageListenerContainer container = new RedisMessageListenerContainer();
        container.setConnectionFactory(connectionFactory);
        container.addMessageListener(listenerAdapter, 
            new PatternTopic("chat.room.*"));  // chat.room.{roomId}
        return container;
    }
    
    @Bean
    public RedisTemplate<String, ChatMessage> chatMessageRedisTemplate(
            RedisConnectionFactory connectionFactory) {
        
        RedisTemplate<String, ChatMessage> template = new RedisTemplate<>();
        template.setConnectionFactory(connectionFactory);
        template.setKeySerializer(new StringRedisSerializer());
        template.setValueSerializer(new Jackson2JsonRedisSerializer<>(ChatMessage.class));
        return template;
    }
}

// 2. 메시지 발행자 (Producer)
// ======================================
@Service
@RequiredArgsConstructor
@Slf4j
public class ChatMessagePublisher {
    
    private final RedisTemplate<String, ChatMessage> redisTemplate;
    private final KafkaTemplate<String, ChatMessage> kafkaTemplate;
    
    /**
     * 메시지를 Redis Pub/Sub로 발행 (실시간 전달)
     * 동시에 Kafka로 전송 (영속성 보장)
     */
    public void publishMessage(ChatMessage message) {
        String channel = "chat.room." + message.getRoomId();
        
        // 1. Redis Pub/Sub로 즉시 발행 (5ms)
        redisTemplate.convertAndSend(channel, message);
        log.info("Published to Redis: channel={}, messageId={}", channel, message.getId());
        
        // 2. Kafka로 비동기 전송 (영속성 보장)
        kafkaTemplate.send("chat-messages", message.getRoomId().toString(), message)
            .addCallback(
                success -> log.info("Kafka 전송 성공: {}", message.getId()),
                failure -> log.error("Kafka 전송 실패: {}", failure.getMessage())
            );
    }
}

// 3. 메시지 구독자 (Subscriber) - 모든 서버에서 실행
// ======================================
@Component
@RequiredArgsConstructor
@Slf4j
public class ChatMessageSubscriber implements MessageListener {
    
    private final SimpMessagingTemplate messagingTemplate;
    private final ObjectMapper objectMapper;
    private final ChatRoomSessionManager sessionManager;  // 세션 관리
    
    @Override
    public void onMessage(Message message, byte[] pattern) {
        try {
            String channel = new String(message.getChannel());
            Long roomId = extractRoomId(channel);  // "chat.room.123" → 123
            
            ChatMessage chatMessage = objectMapper.readValue(
                message.getBody(), 
                ChatMessage.class
            );
            
            // 현재 서버에 연결된 사용자에게만 전송
            Set<String> connectedUserIds = sessionManager.getConnectedUsers(roomId);
            
            for (String userId : connectedUserIds) {
                messagingTemplate.convertAndSendToUser(
                    userId,
                    "/queue/chat.room." + roomId,
                    chatMessage
                );
            }
            
            log.info("Broadcast complete: roomId={}, users={}", roomId, connectedUserIds.size());
            
        } catch (Exception e) {
            log.error("메시지 브로드캐스트 실패", e);
        }
    }
    
    private Long extractRoomId(String channel) {
        return Long.parseLong(channel.substring("chat.room.".length()));
    }
}

    @MessageMapping("/chat.send")
    public void sendMessage(
            @Payload ChatMessageDTO dto,
            @AuthenticationPrincipal User user,
            SimpMessageHeaderAccessor headerAccessor) {
        
        log.info("Received message: roomId={}, userId={}", dto.getRoomId(), user.getId());
        
        // 1. 즉시 ACK 응답 (5ms)
        String sessionId = headerAccessor.getSessionId();
        messagingTemplate.convertAndSendToUser(
            sessionId,
            "/queue/ack",
            Map.of("messageId", dto.getTempId(), "status", "received")

        // 2. 비동기로 메시지 처리
        CompletableFuture.runAsync(() -> {
            try {
                // 2-1. DB 저장 (비동기, 50ms)
                ChatMessage saved = chatMessageService.saveAsync(dto, user);
                
                // 2-2. Redis Pub/Sub 발행 (5ms)

// 5. 세션 관리자 (Redis 기반)
// ======================================
@Component
@RequiredArgsConstructor
public class ChatRoomSessionManager {
    
    private final StringRedisTemplate redisTemplate;
    
    private static final String KEY_PREFIX = "chat:room:sessions:";  // chat:room:sessions:{roomId}
    
    /**
     * 세션 등록: chat:room:sessions:{roomId} → Set(userId:sessionId)
     */
    public void addSession(Long roomId, String userId, String sessionId) {
        String key = KEY_PREFIX + roomId;
        String value = userId + ":" + sessionId;
        redisTemplate.opsForSet().add(key, value);
        redisTemplate.expire(key, Duration.ofHours(24));  // 24시간 TTL
    }
    
    /**
     * 세션 제거
     */
    public void removeSession(String sessionId) {
        // 모든 채팅방에서 해당 sessionId 제거
        Set<String> keys = redisTemplate.keys(KEY_PREFIX + "*");
        for (String key : keys) {
            Set<String> members = redisTemplate.opsForSet().members(key);
            members.stream()
                .filter(m -> m.endsWith(":" + sessionId))
                .forEach(m -> redisTemplate.opsForSet().remove(key, m));
        }
    }
    
    /**
     * 현재 서버에 연결된 사용자 ID 목록 조회
     */
    public Set<String> getConnectedUsers(Long roomId) {
        String key = KEY_PREFIX + roomId;
        Set<String> members = redisTemplate.opsForSet().members(key);
        
        return members.stream()
            .map(m -> m.split(":")[0])  // "userId:sessionId" → "userId"
            .collect(Collectors.toSet());
    }
    
    /**
     * 채팅방 총 연결자 수 (모든 서버 합산)
     */
    public Long getConnectionCount(Long roomId) {
        String key = KEY_PREFIX + roomId;
        return redisTemplate.opsForSet().size(key);
    }
}
```

### 🔧 개선안 2: Redis Cache를 활용한 최근 메시지 조회

#### 문제 상황

```java
// AS-IS: 채팅방 입장 시 최근 100개 메시지 조회
@GetMapping("/chat/rooms/{roomId}/messages")
public List<ChatMessage> getRecentMessages(@PathVariable Long roomId) {
    // DB에서 조회 (250ms)
    return chatMessageRepository
        .findTop100ByRoomIdOrderBySentAtDesc(roomId);
}
```

**문제점:**
- 100명이 동시에 채팅방 입장 → 100번 동일 쿼리 (DB 부하)
- 평균 250ms (사용자 대기 시간)
- 캐시 없이 매번 DB 접근

#### TO-BE: Redis Cache

```java
// ======================================
// 1. Redis Cache 설정
// ======================================
@Configuration
@EnableCaching
public class RedisCacheConfig {
    
    @Bean
    public CacheManager cacheManager(RedisConnectionFactory connectionFactory) {
        RedisCacheConfiguration config = RedisCacheConfiguration.defaultCacheConfig()
            .entryTtl(Duration.ofMinutes(10))  // 10분 TTL
            .serializeKeysWith(
                RedisSerializationContext.SerializationPair.fromSerializer(
                    new StringRedisSerializer()
                )
            )
            .serializeValuesWith(
                RedisSerializationContext.SerializationPair.fromSerializer(
                    new Jackson2JsonRedisSerializer<>(List.class)
                )
            );
        
        return RedisCacheManager.builder(connectionFactory)
            .cacheDefaults(config)
            .transactionAware()
            .build();
    }
}

// ======================================
// 2. 캐시 적용 서비스
// ======================================
@Service
@RequiredArgsConstructor
@CacheConfig(cacheNames = "chatMessages")
public class ChatMessageService {
    
    private final ChatMessageRepository repository;
    private final RedisTemplate<String, ChatMessage> redisTemplate;
    
    private static final String RECENT_MESSAGES_KEY = "chat:room:recent:";  // chat:room:recent:{roomId}
    
    /**
     * 최근 메시지 조회 (Redis 캐시 활용)
     */
    @Cacheable(key = "#roomId + ':recent:100'", unless = "#result == null || #result.isEmpty()")
    public List<ChatMessage> getRecentMessages(Long roomId, int limit) {
        log.info("Cache miss - DB에서 조회: roomId={}", roomId);
        return repository.findTopNByRoomIdOrderBySentAtDesc(roomId, limit);
    }
    
    /**
     * 메시지 저장 시 캐시 갱신
     */
    @CacheEvict(key = "#message.roomId + ':recent:100'")
    public ChatMessage saveAndEvictCache(ChatMessage message) {
        ChatMessage saved = repository.save(message);
        
        // Redis List에도 추가 (최근 100개만 유지)
        String key = RECENT_MESSAGES_KEY + message.getRoomId();
        redisTemplate.opsForList().leftPush(key, saved);  // 최신 메시지를 앞에 추가
        redisTemplate.opsForList().trim(key, 0, 99);  // 100개 초과 시 자동 삭제
        redisTemplate.expire(key, Duration.ofMinutes(30));
        
        return saved;
    }
    
    /**
     * Redis List 기반 최근 메시지 조회 (더 빠름)
     */
    public List<ChatMessage> getRecentMessagesFromRedis(Long roomId, int limit) {
        String key = RECENT_MESSAGES_KEY + roomId;
        List<ChatMessage> cached = redisTemplate.opsForList().range(key, 0, limit - 1);
        
        if (cached == null || cached.isEmpty()) {
            // Cache miss - DB에서 조회 후 Redis에 저장
            List<ChatMessage> fromDB = repository.findTopNByRoomIdOrderBySentAtDesc(roomId, limit);
            if (!fromDB.isEmpty()) {
                redisTemplate.opsForList().rightPushAll(key, fromDB);
                redisTemplate.expire(key, Duration.ofMinutes(30));
            }
            return fromDB;
        }
        
        return cached;
    }
    
    /**
     * 메시지 수정/삭제 시 캐시 무효화
     */
    @CacheEvict(key = "#message.roomId + ':recent:100'")
    public void invalidateCache(ChatMessage message) {
        String key = RECENT_MESSAGES_KEY + message.getRoomId();
        redisTemplate.delete(key);
    }
}
```

| 첫 조회 | 250ms | 250ms (Cache miss) | - |
| 이후 조회 | 250ms | **2ms** | **99.2%** |

### 🔧 개선안 3: Kafka를 활용한 메시지 영속성 보장

#### 기술 선택 이유

| 시나리오 | Redis Pub/Sub | Kafka |
|---------|--------------|-------|
| **실시간 브로드캐스트** | ✅ 적합 (5ms) | ❌ 부적합 (100ms) |
| **메시지 영속성** | ❌ 휘발성 (재시작 시 소실) | ✅ 디스크 저장 (영구 보관) |
| **이벤트 재처리** | ❌ 불가능 | ✅ Consumer Offset 조정 |
| **장애 복구** | ❌ 메시지 유실 | ✅ Replication (3중화) |

**결론:** Redis Pub/Sub (실시간) + Kafka (영속성) 조합

#### 구현 코드

```java
// ======================================
// 1. Kafka 설정
// ======================================
@Configuration
public class KafkaConfig {
    
    @Bean
    public ProducerFactory<String, ChatMessage> producerFactory() {
        Map<String, Object> config = new HashMap<>();
        config.put(ProducerConfig.BOOTSTRAP_SERVERS_CONFIG, "localhost:9092");
        config.put(ProducerConfig.KEY_SERIALIZER_CLASS_CONFIG, StringSerializer.class);
        config.put(ProducerConfig.VALUE_SERIALIZER_CLASS_CONFIG, JsonSerializer.class);
        config.put(ProducerConfig.ACKS_CONFIG, "1");  // 리더 파티션 저장 확인
        config.put(ProducerConfig.RETRIES_CONFIG, 3);
        return new DefaultKafkaProducerFactory<>(config);
    }
    
    @Bean
    public KafkaTemplate<String, ChatMessage> kafkaTemplate() {
        return new KafkaTemplate<>(producerFactory());
    }
    
    @Bean
    public ConsumerFactory<String, ChatMessage> consumerFactory() {
        Map<String, Object> config = new HashMap<>();
        config.put(ConsumerConfig.BOOTSTRAP_SERVERS_CONFIG, "localhost:9092");
        config.put(ConsumerConfig.GROUP_ID_CONFIG, "chat-service-group");

            ack.acknowledge();
            
            log.info("DB 저장 완료: messageId={}", saved.getId());
            
        } catch (Exception e) {
            log.error("메시지 처리 실패: {}", e.getMessage(), e);
            // 실패 시 Kafka가 자동 재시도 (Retry 3회)
```

```java
// ======================================
// 1. Redis Sorted Set 구조
// ======================================
/**
 * Key: "chat:unread:{userId}:{roomId}"
 * Score: messageId (정렬 기준)
 * Member: messageId (중복 방지)
 * 
 * 예시:
 * chat:unread:1:100 → ZADD score=1001 member=1001
 *                    → ZADD score=1002 member=1002
 *                    → ZADD score=1003 member=1003
 * 
 * ZCOUNT chat:unread:1:100 -inf +inf → 3 (읽지 않은 메시지 3개)
 */

@Service
@RequiredArgsConstructor
@Slf4j
public class UnreadMessageCountService {
    
    private final StringRedisTemplate redisTemplate;
    private final ChatMessageRepository messageRepository;
    
    private static final String UNREAD_KEY_PREFIX = "chat:unread:";  // chat:unread:{userId}:{roomId}
    
    /**
     * 새 메시지 발생 시 모든 사용자의 읽지 않은 카운트 증가
     */
    public void incrementUnreadCount(Long roomId, Long messageId, List<Long> userIds) {
        for (Long userId : userIds) {
            String key = UNREAD_KEY_PREFIX + userId + ":" + roomId;
            
            // Sorted Set에 messageId 추가 (Score = messageId)
            redisTemplate.opsForZSet().add(key, messageId.toString(), messageId.doubleValue());
            
            // TTL 7일 (오래된 데이터 자동 삭제)
            redisTemplate.expire(key, Duration.ofDays(7));
        }
        
        log.info("읽지 않은 카운트 증가: roomId={}, messageId={}, users={}", 
            roomId, messageId, userIds.size());
    }
    
    /**
     * 읽지 않은 메시지 개수 조회 (O(1))
     */
    public Long getUnreadCount(Long userId, Long roomId) {
        String key = UNREAD_KEY_PREFIX + userId + ":" + roomId;
        
        // ZCOUNT: O(1) 연산
        Long count = redisTemplate.opsForZSet().zCard(key);
        
        return count != null ? count : 0L;
    }
    
    /**
     * 메시지 읽음 처리 (특정 messageId까지 읽음)
     */
    public void markAsRead(Long userId, Long roomId, Long messageId) {
        String key = UNREAD_KEY_PREFIX + userId + ":" + roomId;
        
        // messageId 이하의 모든 메시지 삭제
        redisTemplate.opsForZSet().removeRangeByScore(key, 0, messageId.doubleValue());
        
        log.info("읽음 처리: userId={}, roomId={}, messageId={}", userId, roomId, messageId);
    }
    
    /**
     * 모든 채팅방의 읽지 않은 카운트 조회 (대시보드용)
     */
    public Map<Long, Long> getAllUnreadCounts(Long userId, List<Long> roomIds) {
        Map<Long, Long> result = new HashMap<>();
        
        // Redis Pipeline으로 일괄 조회 (네트워크 왕복 1번)
        List<Object> counts = redisTemplate.executePipelined(
            (RedisCallback<Object>) connection -> {
                for (Long roomId : roomIds) {
                    String key = UNREAD_KEY_PREFIX + userId + ":" + roomId;
                    connection.zSetCommands().zCard(key.getBytes());
                }
                return null;
            }
        );
        
        for (int i = 0; i < roomIds.size(); i++) {
            Long count = (Long) counts.get(i);
            result.put(roomIds.get(i), count != null ? count : 0L);
        }
        
        return result;
    }
    
    /**
     * DB와 Redis 동기화 (초기화 또는 복구용)
     */
    @Transactional
    public void syncFromDatabase(Long userId, Long roomId) {
        String key = UNREAD_KEY_PREFIX + userId + ":" + roomId;
        
        // 1. 마지막 읽은 메시지 ID 조회
        Long lastReadMessageId = chatReadStatusRepository
            .findLastReadMessageId(userId, roomId)
            .orElse(0L);
        
        // 2. 이후 메시지 목록 조회
        List<ChatMessage> unreadMessages = messageRepository
            .findByRoomIdAndIdGreaterThan(roomId, lastReadMessageId);
        
        // 3. Redis Sorted Set에 일괄 저장
        Set<ZSetOperations.TypedTuple<String>> tuples = unreadMessages.stream()
            .map(msg -> ZSetOperations.TypedTuple.of(
                msg.getId().toString(), 
                msg.getId().doubleValue()
            ))
            .collect(Collectors.toSet());
        
        if (!tuples.isEmpty()) {
            redisTemplate.opsForZSet().add(key, tuples);
            redisTemplate.expire(key, Duration.ofDays(7));
        }
        
        log.info("DB → Redis 동기화 완료: userId={}, roomId={}, count={}", 
            userId, roomId, tuples.size());
    }
}
```

```java
    @GetMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public SseEmitter streamNotifications(@AuthUser User user) {
        String userId = user.getId().toString();
        
        SseEmitter emitter = new SseEmitter(Long.MAX_VALUE);  // 무제한 타임아웃
        emitters.put(userId, emitter);
        
        log.info("SSE 연결: userId={}", userId);
        
        // 연결 즉시 현재 읽지 않은 알림 개수 전송
        try {
            Long unreadCount = countService.getUnreadCount(user.getId());
            emitter.send(SseEmitter.event()
                .name("unread-count")
                .data(Map.of("count", unreadCount))
            );
        } catch (IOException e) {
            log.error("초기 알림 전송 실패", e);
        }
        
        // 연결 해제 시 정리
        emitter.onCompletion(() -> {
            emitters.remove(userId);
            log.info("SSE 연결 해제: userId={}", userId);
        });
        
        emitter.onTimeout(() -> {
            emitters.remove(userId);
            log.warn("SSE 타임아웃: userId={}", userId);
        });
        
        emitter.onError(e -> {
            emitters.remove(userId);
            log.error("SSE 에러: userId={}", userId, e);
        });
        
        return emitter;
    }
    
    /**
     * 특정 사용자에게 알림 전송

    public void sendNotification(String userId, Object data) {
        SseEmitter emitter = emitters.get(userId);

                emitter.send(SseEmitter.event()
                    .name("notification")
                    .data(data)
                );
                log.info("알림 전송 성공: userId={}", userId);
            } catch (IOException e) {
                log.error("알림 전송 실패: userId={}", userId, e);
                emitters.remove(userId);
            }
        }
    }
```

```java
 *                        → ZADD score=1701234568 member=1002
 * 
 * ZCOUNT notification:unread:1 -inf +inf → 2 (읽지 않은 알림 2개)
 */

@Service
@RequiredArgsConstructor
public class UnreadNotificationCountService {
    
    private final StringRedisTemplate redisTemplate;
    
    private static final String UNREAD_KEY_PREFIX = "notification:unread:";
    
    /**
     * 새 알림 발생 시 카운트 증가
     */
    public void addNotification(Long userId, Long notificationId) {
        String key = UNREAD_KEY_PREFIX + userId;
        double score = System.currentTimeMillis();
        
        redisTemplate.opsForZSet().add(key, notificationId.toString(), score);
        redisTemplate.expire(key, Duration.ofDays(30));
    }
    
    /**
     * 읽지 않은 알림 개수 조회 (O(1))
     */
    public Long getUnreadCount(Long userId) {
        String key = UNREAD_KEY_PREFIX + userId;
        Long count = redisTemplate.opsForZSet().zCard(key);
        return count != null ? count : 0L;
    }
    
    /**
     * 알림 읽음 처리
     */
    public void markAsRead(Long userId, Long notificationId) {
        String key = UNREAD_KEY_PREFIX + userId;
        redisTemplate.opsForZSet().remove(key, notificationId.toString());
    }
    
    /**
     * 모두 읽음 처리
     */
    public void markAllAsRead(Long userId) {
        String key = UNREAD_KEY_PREFIX + userId;
        redisTemplate.delete(key);
    }
}
```

```java
// ======================================
// 1. RabbitMQ 설정
// ======================================
@Configuration
public class RabbitMQConfig {
    
    public static final String PUSH_NOTIFICATION_QUEUE = "push-notification-queue";
    public static final String PUSH_NOTIFICATION_EXCHANGE = "push-notification-exchange";
    
    @Bean
    public Queue pushNotificationQueue() {
        return QueueBuilder.durable(PUSH_NOTIFICATION_QUEUE)
            .withArgument("x-max-priority", 10)  // Priority Queue
            .build();
    }
    
    @Bean
    public DirectExchange pushNotificationExchange() {
        return new DirectExchange(PUSH_NOTIFICATION_EXCHANGE);
    }
    
    @Bean
    public Binding pushNotificationBinding() {
        return BindingBuilder
            .bind(pushNotificationQueue())
            .to(pushNotificationExchange())
            .with("push");
    }
    
    @Bean
    public RabbitTemplate rabbitTemplate(ConnectionFactory connectionFactory) {
        RabbitTemplate template = new RabbitTemplate(connectionFactory);
        template.setMessageConverter(new Jackson2JsonMessageConverter());
        return template;
    }
}

// ======================================
// 2. 대량 푸시 알림 발송
// ======================================
@Service
@RequiredArgsConstructor
@Slf4j
public class PushNotificationProducer {
    
    private final RabbitTemplate rabbitTemplate;
    
    /**
     * 100,000명에게 푸시 알림 발송 (비동기)
     */
    public void sendBulkPushNotification(String message, List<Long> userIds) {
        log.info("대량 푸시 시작: users={}", userIds.size());
        
        // RabbitMQ에 100,000개 메시지 발행 (1초 소요)
        for (Long userId : userIds) {
            PushNotificationMessage msg = new PushNotificationMessage(
                userId,
                "공지사항",
                message,
                NotificationPriority.NORMAL
            );
            
            rabbitTemplate.convertAndSend(
                RabbitMQConfig.PUSH_NOTIFICATION_EXCHANGE,
                "push",
                msg,
                m -> {
                    m.getMessageProperties().setPriority(msg.getPriority().getValue());
                    return m;
                }
            );
        }
        
        log.info("대량 푸시 발행 완료: users={}", userIds.size());
    }
}

// ======================================
// 3. 푸시 알림 Consumer (10개 인스턴스 병렬 처리)
// ======================================
@Component
@RequiredArgsConstructor
@Slf4j
public class PushNotificationConsumer {
    
    private final FcmService fcmService;
    
    /**
     * RabbitMQ에서 푸시 알림 수신 → FCM 전송
     * 10개 스레드 병렬 처리
     */
    @RabbitListener(
        queues = RabbitMQConfig.PUSH_NOTIFICATION_QUEUE,
        concurrency = "10"  // 10개 Consumer 동시 실행
    )
    public void consume(PushNotificationMessage message) {
        try {
            log.info("푸시 전송 시작: userId={}", message.getUserId());
            
            // FCM 푸시 전송 (50ms)
            fcmService.sendPush(
                message.getUserId(),
                message.getTitle(),
                message.getMessage()
            );
            
            log.info("푸시 전송 성공: userId={}", message.getUserId());
            
        } catch (Exception e) {
            log.error("푸시 전송 실패: userId={}", message.getUserId(), e);
            // RabbitMQ가 자동 재시도 (x-retry-count)
            throw e;
        }
    }
}

// ======================================
// 4. 우선순위 큐 지원
// ======================================
@Getter
@AllArgsConstructor
public enum NotificationPriority {
    URGENT(10),    // 긴급 (시스템 알림)
    HIGH(7),       // 높음 (멘션)
    NORMAL(5),     // 보통 (일반 채팅)
    LOW(1);        // 낮음 (마케팅)
    
    private final int value;
}
```
